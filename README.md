# Subashree.S | Creative Portfolio

A modern, responsive personal portfolio website designed to showcase my engineering background, technical skills, and software projects. 

## Live Demo
[View Live Site](https://virtuososubashree.github.io/Portfolio_Subashree_S) 


## Features
* **Modern UI/UX:** Features a sleek dark theme with glassmorphism design elements.
* **Interactive Elements:** Includes a typewriter text effect, smooth scroll-reveal animations, and dynamic floating background orbs.
* **Fully Responsive:** Adapts seamlessly to all devices (desktop, tablet, and mobile) with a custom mobile navigation menu.
* **Zero Frameworks:** Built entirely using vanilla HTML5, CSS3, and JavaScript for optimal performance and complete design control.

## Technologies Used
* **HTML5:** Semantic layout and structuring.
* **CSS3:** Custom variables, Flexbox, CSS Grid, animations, and backdrop-filters.
* **JavaScript:** DOM manipulation, Intersection Observer API for scroll animations, and custom typing effects.

## Local Setup
Simply clone or download this repository and open the `index.html` file in any modern web browser to view the site locally. No build tools or package managers are required.
